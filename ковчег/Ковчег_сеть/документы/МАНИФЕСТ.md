## Зачем мы это делаем

Мы создаём **живую библиотеку знаний** на основе git.sib и RAGU.  
Это не просто «ещё один форк». Это **интеграция сибирской науки в сибирскую инфраструктуру**.

## Что мы строим

| Компонент | Роль |
|-----------|------|
| **git.sib** | Хранилище кода (локальный GitHub) |
| **RAGU** | Умный слой над хранилищем (графы знаний) |
| **Смысловая сеть** | Карта связей между элементами |
| **Феникс** | Интерфейс для взаимодействия |

## Принципы

1. **Локальность** — всё работает на твоём устройстве, без интернета.
2. **Этичность** — данные принадлежат человеку, а не корпорации.
3. **Сибирский дух** — мы строим здесь, для мира.
4. **Открытость** — код доступен, изменения возвращаются сообществу.

## Для кого это

- Для тебя (Архитектора) — как инструмент управления знаниями.
- Для Новосибирска — как прототип локальной цифровой культуры.
- Для мира — как пример этичного ИИ и открытой библиотеки кода.
