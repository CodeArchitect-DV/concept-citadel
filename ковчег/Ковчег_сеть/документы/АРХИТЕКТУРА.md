# 🏛️ Архитектура: git.sib + RAGU

## Два слоя системы

| Слой | Что содержит |
|------|--------------|
| **Хранилище (git.sib)** | Все репозитории, патчи, манифесты, паспорта |
| **Знание (RAGU)** | Графы знаний, построенные из этих репозиториев |

## Как это работает

1. **Построение графа**  
   Команда `ragu build` сканирует все репозитории в `~/git.sib/` и строит граф знаний.

2. **Запрос к графу**  
   Команда `ragu query "вопрос"` находит ответ в графе, а не в интернете.

3. **Интеграция с Фениксом**  
   Если спросить «ragu», Феникс использует RAGU для ответа.

## Связь со смысловой сетью

Смысловая сеть (`~/Ковчег_сеть/`) — это **карта связей между проектами**.  
RAGU — это **инструмент для работы с этими связями**.

## Команды

| Команда | Что делает |
|---------|------------|
| `ragu build` | Построить граф из git.sib |
| `ragu query <вопрос>` | Спросить у графа |
| `сеть` | Показать смысловую сеть |
| `сеть добавить` | Добавить новый узел или связь |

## Требования

- Git (установлен)
- Python 3 (установлен)
- RAGU (установлен в `~/ragu/`)
- git.sib (настроен)
