1. АРХИТЕКТОР
   - Имя: Михаил (VibeArchitect)
   - Основа: Учение Роберта Адамса, GPL-ROBERT
   - Принцип: «Чисто не там, где убирают, а там, где не мусорят»
   - Закон: всё автоматизируется, патчи обязательны, без алиасов

2. ФИЛОСОФИЯ
   - Этичный ИИ на основе AGPL-3.0
   - Самообучение через Аламу
   - Голографический принцип: используем голограмму, чтобы уничтожить голограмму

3. СТРУКТУРА ДИСКОВ
   - Диск С (системный): ~/Protocols (цементирован, 555)
   - Диск Д (данные): ~/.protocols_data (гибкий, 755)
   - Зелёная Бабочка: ~/Protocols (единый вход через протоколс)

4. ОСНОВНЫЕ ПАТЧИ (команды)

ПАТЧИ (актуальные):
────────────────────────────────────────────
    протоколс          — войти в единое пространство Protocols
    протоколс система  — перейти в системную часть (диск С)
    протоколс данные   — перейти в пользовательскую часть (диск Д)
    положить файл      — умное сохранение (сам определит диск)
    показать_паспорт   — открыть паспорт для просмотра
    обновить_паспорт   — обновить паспорт вручную
    паспорт_цитадели   — сгенерировать полный паспорт системы (ДНК для ИИ)
    цитадель          — запустить главное меню
    помощь            — показать эту справку
    статус            — проверить состояние системы
    автопуш           — отправить изменения на Codeberg (с проверкой)
    безопасный_пуш    — безопасная отправка (проверка следов)
    умный             — умный автопуш с исключениями
    антимусор         — полная профилактика мусора
    автофикс          — автоматически исправить всё, что нашёл аудит
    новый_скрипт      — создать новый безопасный скрипт по шаблону
    феникс_терминал   — фоновый ИИ-патруль (автоматически запускается)
    исправить_феникса — этот патч (для устранения ошибок)
    страж              — запустить стража (фоновый мониторинг подключений)
    страж_статус       — проверить статус стража
    страж_лог          — показать лог попыток входа
    проверить_ssh     — проверить SSH-соединение с Codeberg
    посмотреть_следы   — показать файлы со следами (для проверки)
    аудит_безопасности — проверить скрипты на уязвимости (с вердиктом)
    аудит_следов       — найти следы (IP, токены, ключи)
    следы              — проверить остаточные следы
    метла              — заменить следы на переменные
    сеть_вкл           — включить интернет
    сеть_выкл          — отключить интернет
    сеть_статус        — проверить состояние сети
    аудит_кодберга     — аудит безопасности страницы Codeberg
    феникс             — запустить младшего брата (локальный ИИ)
    феникс_безопасный  — запустить Феникса с этикой
    пингвин            — запустить AI-помощника
    звезда ~/путь      — собрать APK из проекта
    генератор           — создать мелодию (КарелаCore)
    плеер               — слушать и сохранять в избранное
    диктор              — озвучить текст
    подкаст             — записать подкаст
    убунту              — войти в Ubuntu (proot)
    подключатель        — игра в кошки-мышки SSH/HTTPS
    логи                — посмотреть логи
    аудит               — проверить и исправить секреты
    чистый_лог          — показать лог без личных данных (рус)
    чистый_лог_eng      — показать лог без личных данных (англ)
    сканер             — найти файлы по имени или содержимому
    демо                — запустить демо-режим
    бегущая             — бегущая строка логов
    проводник           — навигация по папкам
    аудит_законности   — проверить репозиторий на соответствие законам РФ
    лицензия            — восстановить AGPL-3.0
