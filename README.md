## 🛠️ Проекты

### 1. Цитадель — этичный ИИ для каждого
- **Описание:** локальная ИИ-экосистема на телефоне (Алама, Феникс, Лягушка, Страж).
- **Стек:** Termux, Bash, Python, Java, Git, AGPL-3.0.
- **Ссылки:**  
  - [GitHub](https://github.com/CodeArchitect-DV/concept-citadel)  
  - [Codeberg](https://codeberg.org/VibeArchitect/concept-citadel)

### 2. Корела Кор — музыкальный лейбл в терминале
- **Описание:** генерация музыки, клипов, обложек, релизов, публикация.
- **Стек:** Bash, sox, ffmpeg, ImageMagick, Алама.
- **Ссылки:** в составе Цитадели.

### 3. Лягушка — создатель приложений без кода
- **Описание:** по текстовому описанию создаёт APK и веб-приложения.
- **Стек:** Java, Bash, Android SDK (минимум).

### 4. Фильтр_агент — защита личных данных
- **Описание:** маскирует IP, email, телефон, токены в файлах.
- **Стек:** Bash, регулярные выражения.

### 5. Маркировка — юридическая защита ИИ-контента
- **Описание:** добавляет метку «Сгенерировано ИИ» во все файлы.
- **Стек:** Bash.
